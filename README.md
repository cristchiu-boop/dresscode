# dresscode

衣序是一款移动端优先的衣橱诊断 Demo，帮助用户盘活已有衣物、理解搭配逻辑，并获得鞋袜配色建议。

## 在线体验

https://cristchiu-boop.github.io/dresscode/

## 当前功能

- 拍摄或选择衣物照片
- 照片压缩后保存在当前浏览器的 IndexedDB
- 刷新或重新打开页面后继续使用本地衣橱
- 一键清空当前设备中的衣橱数据
- 衣柜结构与色彩诊断
- 三套衣橱组合及鞋袜配色建议
- 基于衣柜缺口的购买建议

## 隐私与存储

用户照片不会上传到 GitHub 或其他服务器。照片和衣物元数据只保存在当前浏览器；清理浏览器数据、使用无痕模式或更换设备会导致数据不可用。

当前诊断结果使用预设规则模拟 AI 分析，主要用于验证产品路径与信息表达。
